# Task: Thêm hàm multiply vào utils.py và viết test trong test_utils.py

## Mô tả
Triển khai hàm multiply(a, b) trả về tích a * b vào utils.py và viết bộ kiểm thử đơn vị trong test_utils.py sử dụng framework unittest để xác minh tính đúng đắn.

## Yêu cầu
- Tạo file utils.py tại thư mục gốc repository nếu chưa có
- Định nghĩa hàm multiply(a, b) trả về giá trị a * b trong utils.py
- Tạo file test_utils.py kế thừa unittest.TestCase để kiểm thử hàm multiply
- Bao phủ các trường hợp kiểm thử: số nguyên dương, số âm, số 0, số thực (float)

## Tiêu chí nghiệm thu
- Hàm multiply(a, b) tồn tại trong utils.py và trả về đúng tích của a và b
- File test_utils.py sử dụng unittest framework và bao phủ đầy đủ các test case cần thiết
- Tất cả các unit tests trong test_utils.py chạy thành công (exit code 0)

  - Đảm bảo hàm hỗ trợ tính toán chính xác đối với cả kiểu số nguyên (`int`) và số thực (`float`).

## 3. Test Strategy
Các test case cần xây dựng trong lớp `TestUtils` kế thừa từ `unittest.TestCase`:
- `test_multiply_positive_numbers`: Kiểm tra tích hai số nguyên dương (ví dụ: `2 * 3 == 6`).
- `test_multiply_negative_numbers`: Kiểm tra tích các số âm và tích số âm với số dương (ví dụ: `(-2) * (-3) == 6`, `(-2) * 3 == -6`).
- `test_multiply_by_zero`: Kiểm tra tích khi một hoặc cả hai thừa số bằng 0 (ví dụ: `5 * 0 == 0`, `0 * 0 == 0`).
- `test_multiply_floats`: Kiểm tra phép nhân với số thực (ví dụ: `2.5 * 2 == 5.0`, `0.1 * 0.2` sử dụng `assertAlmostEqual`).
- `test_multiply_identity`: Kiểm tra phần tử đơn vị của phép nhân (ví dụ: `7 * 1 == 7`).
